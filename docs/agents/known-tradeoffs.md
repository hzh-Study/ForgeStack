# 已知取舍（评审先读）

以下取舍是有意为之，不是遗漏。评审时先按本文件判断，避免当作缺陷重复提出。

- **状态字段用 String + 枚举常量**：数据库存字符串，便于跨端展示与数据迁移；不使用 `@EnumValue` 枚举映射，牺牲编译期约束换取可读性与兼容性。
- **移除通用 `sys_user` 与旧用户管理**：由货主、物流公司、司机、管理员四角色资料表替代；账号体系围绕实名与入驻设计，旧表不再保留。
- **不开放公开 `/files/**`**：文件统一走鉴权接口按归属读取，避免链接泄露绕过数据隔离；代价是前端需携带 Token 取流。
- **管理员实名尚未单独落身份证核验记录**：管理员账号只维护实名信息，身份证核验流水尚未单独建表，范围限定在管理员侧。
- **权限以路由前缀 + `@SaCheckRole`/Service 归属校验为主**：未全量铺 `@SaCheckPermission`；细粒度权限留待后续，当前依赖角色与数据归属双校验。
- **H2 默认测试 + 独立 MySQL 冒烟检查**：日常测试用 H2 保证速度，MySQL 方言与 schema 由 `mysql-check` profile 单独覆盖。
- **`demo-data.sql` 一次性写入**：脚本面向空库演示环境，重复执行会冲突，不做幂等；请勿在已有演示数据的库上重跑。
- **开发环境登录自动填充由 `.env.development` 控制**：`VITE_DEBUG_AUTOFILL=true` 仅用于本地调试，生产构建不读取该文件。
