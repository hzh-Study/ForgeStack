# 实名校验通过适配器接入，本期以本地模拟实现

需求文档要求实名校验由系统自动完成，并包含企业法定代表人的实名校验，但平台没有第三方实名核验服务的账号、密钥与费用。决定定义实名校验适配器接口，本期使用本地模拟实现：按可配置规则返回通过与不通过，并记录校验结果与不通过原因；真实供应商后续实现同一接口即可替换。

## 考虑过的替代方案

- 直接接入真实第三方实名核验：需要申请账号、承担调用费用，当前不具备条件。
- 改为管理员人工审核实名：违背「实名自动校验、入驻人工审核」的两段式设计，且会把两类审核混在一起。

## 后果

- 模拟校验结果不具备法律效力，不能直接用于生产环境。
- 切换真实供应商只替换适配器实现，业务规则与留痕格式不变。
