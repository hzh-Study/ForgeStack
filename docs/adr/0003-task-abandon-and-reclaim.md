# 未出发任务允许司机弃单与物流公司强制回收

需求文档 v1.2 规定任务归属一经确定即锁定、不可再次分配，且没有异常退出通道；司机离职、车辆故障或长期失联时，该任务无法执行，订单永久卡死。决定在任务未出发时增加两条受控出口：司机可主动弃单，物流公司可强制回收；两者均须填写原因、二次确认并留痕，任务回到可指派状态，历史领取与回收记录保留。

## 考虑过的替代方案

- 完全线下处理：订单变成死单，与「运单须全部任务完成才算完成」直接冲突。
- 超时自动回收：需要另行定义超时时长、提醒与判定规则，超出本期范围。

## 后果

- 弃单或强制回收后，任务回到「待指派」状态，公司可重新指派或再次开放到公司任务池自抢；原领取与回收记录保留，弃单与回收作为留痕事件而非新的终态。
- 订单能否取消仍只取决于「是否存在已出发的任务」，不受弃单与回收影响。
