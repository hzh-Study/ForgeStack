# 报销在任务出发后可提交，取消订单不再存在待审报销

需求文档 v1.2 只要求报销单关联运输任务，未定义提交时点；同时 7.1 又写明「取消后已产生的报销单仍可继续审核」，而取消的前提是全部任务未出发。两者只有允许出发前提交报销时才可能同时成立。决定报销单只能在任务出发打卡之后提交，订单取消时必然不存在待审或已通过的报销单，7.1 中「取消后报销仍可审核」的条款作废。

## 考虑过的替代方案

- 任务领取后即可提交：会出现已取消订单仍挂着待审报销单的悬空状态，需要额外定义审核与额度处理。
- 任务完成后才可提交：跨月运输的费用会被挤到下月，破坏按自然月累计的额度口径。

## 后果

- 司机在出发前垫付的油费需在出发打卡后再提交，不影响实际报销，只影响提交时点。
- 取消订单不需要处理报销单的后续流转，取消路径更简单。
