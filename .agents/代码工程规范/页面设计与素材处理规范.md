# 页面设计与素材处理规范

## 1. 文档目的

本文档用于约束页面设计参考、素材选择、图片生成、压缩与接入。

效果图和素材图按任务需要提供，不作为所有页面开发的前置条件。

## 2. 适用范围

适用于以下场景：

- 用户提供后台管理端效果图，希望页面尽量还原。
- 用户提供前台用户端效果图，希望页面尽量还原。
- 用户提供少量页面效果图，其他同类型页面需要根据已提供效果图和既有实现风格延展。
- 用户提供参考图片，或要求生成页面所需的插画、背景等独立素材。
- 任务涉及 ImageGen 图片生成、图片压缩或将图片接入页面、上传入库；即使没有效果图，也必须遵守第 6 节。

## 3. 设计输入判断

- 用户要求按图还原时，先确认页面与端侧，再查找对应效果图、同端参考页面和已有素材。
- 后台列表、表单、配置、详情抽屉及同类前台记录页，可根据同端已有页面延展；保持布局、信息密度、按钮、表格、弹窗等风格一致。
- 用户要求精确还原的页面，或首页、登录页等关键视觉页面缺少必要设计输入时，说明已查找的范围和缺失内容，先完成不依赖该输入的工作，再请求补充。用户允许自行设计时可继续实现。
- 素材图是可选输入。先按第 4 节判断是否需要独立图片，再依次考虑已有资源、图标库、CSS/SVG 和 ImageGen；不因缺少独立素材图暂停整个页面。
- 参考效果图中的浏览器外壳、地址栏和示意装饰不作为业务页面内容，用户明确要求除外。

## 4. 素材与页面代码的边界

素材处理只针对页面中有明确视觉设计价值、需要复用或无法用 CSS/HTML 稳定还原的真实装饰素材、品牌素材、插画素材、背景素材和复杂图形。

- 商品图、头像、内容封面和列表图片属于业务数据，使用已有资源、数据库字段或真实上传结果；用户未明确要求时，不通过 ImageGen 补造业务数据。
- 二维码由对应业务能力生成，不从效果图截取作为正式数据。
- 按钮、搜索框、分页、表单、卡片、分隔线和骨架屏用 Vue、Element Plus、HTML/CSS 实现；简单图标优先使用图标库或 SVG。
- 只有复杂纹理、异形轮廓、品牌图案等无法稳定用代码表达的装饰才生成图片，文字和交互仍由代码实现。
- 页面结构和交互由代码实现，图片只用于实际需要的视觉素材。

## 5. ImageGen 素材生成规则

按素材需要复用项目资源或使用内置 ImageGen 生成。工具不可用或生成失败时，说明缺失素材并继续不依赖它的工作。

- 生成前根据用户描述、参考图或已有页面，确认素材的主体、构图、风格、配色、尺寸比例及使用位置。
- 使用内置 ImageGen 工具生成插画、背景、装饰图或复杂图形，保持与页面一致的视觉风格。
- 每个输出图片对应一个独立素材，不将多个无关素材合成素材板，不生成整页截图替代 Vue 页面。
- 需要透明背景的素材必须生成真实透明背景，不使用白底或棋盘格图片冒充透明图片。
- 提示中只描述所需素材，避免出现无关文字、水印或页面外壳。
- 文件名必须描述素材内容或页面用途，避免 `asset_01.png` 这类泛名。
- 输出目录优先放在对应前端工程的 `src/assets/images/页面模块/` 下。
- 工具生成结果必须复制或保存到项目目录，不能只引用工具默认输出目录中的文件。
- 接入前检查素材内容、尺寸比例、边缘、透明背景和风格一致性；不符合页面效果时调整提示并重新生成。
- 接入后检查实际页面中的缩放、裁剪、对齐和显示效果，避免拉伸变形或遮挡业务内容。

## 6. 图片压缩与体积验收

### 6.1 执行顺序

- 所有 ImageGen 生成并用于本项目的图片，都必须执行“生成 → 检查原图 → 按展示尺寸缩放与压缩 → 核对体积和画质 → 接入页面或上传入库 → 页面自检”。不能跳过压缩直接交付。
- 本规则覆盖前后台装饰背景、插画、封面、详情相册及用户明确要求生成的业务配图；批量生成时必须逐张处理。
- 原始生成文件保留不覆盖，压缩图另存；业务页面及上传接口只使用验收后的压缩版本，不能把原图作为实际加载资源。

### 6.2 压缩方式与体积目标

- 普通照片、插画和背景优先输出 WebP；需要透明背景时保留真实 Alpha 通道。仅在兼容性或画质要求明确需要时保留优化后的 PNG/JPEG。
- 根据实际显示尺寸决定像素尺寸，保持比例，不放大原图，不为小缩略图保留无必要的超大分辨率；详情图需兼顾大图预览清晰度。
- 默认体积目标：图标及小装饰不超过100 KB，常规封面、相册图不超过500 KB，整页大背景不超过1 MB。以上为压缩目标，不是上传接口的文件大小上限。
- 超过目标时继续调整尺寸、编码质量或格式，不能只改扩展名、仅声明“已压缩”或把过大的原文件上传。若确因清晰度或透明细节需要保留更大文件，应在交付记录写明具体文件、大小及原因，不默认要求用户审批。
- 压缩后若体积反而增大，应重新选择编码参数或格式；不能为了减小体积造成明显模糊、色带、锯齿或透明边缘异常。

### 6.3 验证与交付记录

- 每张图片核对实际文件字节数、像素尺寸、格式；批量素材统计压缩前后总大小、压缩比例及最大单图大小，并记录逐文件结果。
- 在真实页面检查缩略图、背景或大图预览的清晰度、透明效果和加载结果。业务图片还需确认数据库引用的是压缩图的系统相对路径。
- 压缩脚本、中间文件和验收记录放到项目根目录 `temp/`；最终静态素材放到对应前端素材目录，业务图片通过后端上传接口保存。
- 交付说明应包含图片数量、压缩前后总大小、最终素材位置和超过目标的例外情况。未完成压缩及核对，不得宣称图片素材已完成交付。
