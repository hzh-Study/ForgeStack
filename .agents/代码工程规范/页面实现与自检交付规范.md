# 页面实现与自检交付规范

## 1. 适用范围

用于前端页面、布局和交互的实现与验收。页面修改完成后，执行任务的 agent 必须先自行验收，再交付用户。

## 2. 页面实现

- 管理端 `backend-ui` 遵守 `Vue3-ElementPlus后台项目分层规范.md`；用户端 `frontend-ui` 遵守 `Vue3前台项目分层规范.md`。
- 页面分层、公共组件复用和请求封装按当前端侧分层规范执行。
- 按用户要求实现相关页面，不主动扩展无关业务。
- 涉及效果图、素材图或图片处理时，读取 `页面设计与素材处理规范.md`。

## 3. 浏览器验收

使用当前会话提供的浏览器或页面验证能力，直接打开真实页面、操作并查看截图。同一任务复用浏览器标签页，修改后刷新或切换路由继续验收。

按本次修改范围检查：

- 路由访问、导航跳转和刷新是否正常。
- 排版、间距、文字、图标和图片是否正常，有无溢出、重叠、遮挡或变形。
- 按真实用户路径完成核心操作，例如搜索、分页、表单校验、提交和弹窗交互，确认结果符合预期。
- 已有后端接口必须完成联调，确认数据展示、提交结果和失败提示；涉及数据库时核对前后端字段及实际数据。
- 检查控制台错误和失败请求；当前工具无法查看时，用服务日志或接口验证补充，并如实说明未检查项。
- 默认按桌面浏览器验收，仅在用户要求时检查移动端。

发现问题后先修复，再在原页面复验。只完成构建或打开页面，不算完成浏览器验收。浏览器能力不可用时，说明原因和已完成的验证。

## 4. 自检服务与清理

- 服务启动、端口选择、进程记录和清理统一遵守 `终端命令执行规范.md`。
- 只清理本次创建且不再需要的浏览器标签页，不关闭用户原有页面或整个浏览器；用户要求保留的页面予以保留。
- 截图、日志和自检记录按终端规范保存；截图仅在会话内展示时，记录对应页面和检查结果即可。

## 5. 交付说明

最终回复简要说明：

- 修改的页面或端侧。
- 实际验收地址、核心操作及结果，以及相关构建或测试结果。
- 未完成的检查、未接入的功能或仍存在的问题；没有则省略。
- 有落盘截图或报告时提供路径，并说明本次自检服务的清理或保留情况。

所有结论必须来自实际执行，不得将未检查项写成通过。
