# 终端命令执行规范

## 1. 终端与工作目录

- Windows 默认使用 PowerShell 7（`pwsh`）；仅在兼容性需要或用户指定时使用其他 shell。
- 执行前确认当前端侧：后端命令在 `server-api`，管理端命令在 `backend-ui`，用户端命令在 `frontend-ui`，小程序与 APP 命令在 `uniapp-ui` 执行。
- 常用验证命令：后端优先使用工程内 Maven Wrapper，Linux/macOS 执行 `./mvnw -B -DskipTests package`，Windows 执行 `.\mvnw.cmd -B -DskipTests package`；前端优先 `npm ci` 后 `npm run build`，小程序端 `npm run build:mp-weixin`；具体以当前工程配置为准。
- 不要依赖本机全局 Maven 版本；Wrapper 已锁定 Maven 3.9.9。

## 2. 临时产物

- 临时产物统一放在项目根目录 `temp/`：截图放 `temp/screenshots/`，测试报告放 `temp/test-results/`，日志放 `temp/logs/`，一次性脚本放 `temp/scripts/`。
- 不向 `.agents/` 或各端模块目录新增临时运行产物。
- 只有用户确认需要长期维护的项目级正式脚本，才新建或使用根目录 `scripts/`。

## 3. 服务启动与清理

- 启动自检服务前检查端口，为涉及的端侧选择空闲端口，不复用或停止用户正在使用的服务。
- 记录本次启动的端侧、URL、端口和进程 ID。同一任务复用这些服务和端口，前端优先使用热更新。
- 确需重启时只重启受影响的服务并沿用原端口；原端口无法使用时更新记录。
- 全部修复与复验结束后，关闭本次启动且不再需要的所有前后端服务，并在最终回复前确认端口释放；用户明确要求保留的服务除外，需记录其地址与进程信息。
- 结束进程前确认其属于本次任务。只剩端口信息时，先查询进程和命令行，再决定是否关闭。
- 清理失败时说明端侧、端口、进程 ID 和原因，不误关用户服务。

端口与进程检查示例：

```powershell
Get-NetTCPConnection -LocalPort 5180 -ErrorAction SilentlyContinue | Select-Object LocalPort,OwningProcess
Get-CimInstance Win32_Process -Filter "ProcessId = 进程ID" | Select-Object ProcessId,CommandLine
```

Vite 指定自检端口示例：

```powershell
npm run dev -- --host 127.0.0.1 --port 5180 --strictPort
```
