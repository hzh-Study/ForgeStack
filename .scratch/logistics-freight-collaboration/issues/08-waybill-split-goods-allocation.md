# 08: 运单拆分与货物分配

**What to build:** 物流公司可以把运单的货物明细按整行拆成多个运输任务，支持增量拆分与逐批派车；任一任务出发前必须把全部货物行分配完毕，运单详情能看出哪些货物已分配、哪些未分配。

**Blocked by:** 07

**Status:** resolved

- [x] 运单按货物明细整行创建多个运输任务，同一明细行不能拆到两个任务
- [x] 支持增量创建任务，不必一次性把全部货物分配完
- [x] 运单详情展示已分配与未分配货物行，未分配完毕时任务不能出发
- [x] 每个任务展示承载货物、待指派状态与所属运单
- [x] 拆分与任务创建记录操作人、时间与货物分配结果
- [x] 物流公司只能拆本公司运单，其他公司不可见
- [x] 后端 HTTP API 测试覆盖整行约束、增量拆分、出发前全部分配与数据隔离
