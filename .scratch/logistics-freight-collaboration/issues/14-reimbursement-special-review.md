# 14: 报销与特殊审核

**What to build:** 司机在任务出发打卡后提交报销单，一个任务可多笔；系统按司机加自然月累计额度，超限仍可提交并进入特殊审核；物流公司可审核通过或驳回，驳回后司机可修改重提，通过后不可撤销。

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] 任务出发打卡前不能提交报销；报销必须关联该运输任务，金额大于 0、费用类型必选、凭证照片必填
- [ ] 一个任务可提交多笔；司机可看到当月累计与剩余额度
- [ ] 当月累计计入待审核与已通过，被驳回不计；驳回重提按最新版本计一次；归属月份按费用发生时间
- [ ] 额度按司机加自然月配置，平台默认 5000 元/月，物流公司可按司机覆盖；额度变更只影响新提交单据
- [ ] 超限单按提交时的累计与额度快照标记，仍可提交并进入特殊审核，复核必须填写审核说明
- [ ] 审核通过为终态不可撤销；驳回必须填写原因，司机可修改重提并保留历史版本与审核记录
- [ ] 管理员只读查看报销与审核结果，不参与审批
- [ ] 后端 HTTP API 测试覆盖提交时点、累计口径、跨月归属、超限快照、特殊审核、驳回重提与终态
