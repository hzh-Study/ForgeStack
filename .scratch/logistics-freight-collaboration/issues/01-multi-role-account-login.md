# 01: 多角色账号与手机号登录

**What to build:** 管理员、货主、物流公司、司机四种账号可以分别在后台管理端、前台用户端与司机小程序登录，并进入各自的角色视图；全角色统一手机号加密码登录，司机首次登录强制改密，跨角色访问被拒绝。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 后台管理端可创建并登录管理员账号，前台用户端可注册货主与物流公司账号，司机可用预置测试账号登录小程序
- [ ] 手机号加密码登录成功后返回角色与端侧信息，三个前端按角色进入对应菜单，不出现越权入口
- [ ] 司机首次登录强制修改初始密码，改密前不能进入业务页面，旧密码立即失效
- [ ] 停用账号登录被拒绝；跨角色调用业务接口返回无权限
- [ ] 后端 HTTP API 测试覆盖登录、角色路由、首次改密与停用拒绝
