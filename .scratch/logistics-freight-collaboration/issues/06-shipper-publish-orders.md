# 06: 货主发布与我的订单

**What to build:** 货主可以保存草稿、填写完整发货单并发布，发布后的订单进入订单池；货主可在“我的订单”中按状态与时间查看自己发布的订单；接单前的公开投影隐藏隐私字段。

**Blocked by:** 03

**Status:** resolved

- [x] 货主可保存草稿并反复编辑，草稿不进入订单池
- [x] 发货单包含运费报价、多行货物明细、一个装货点、一个卸货点、约定提货时间、约定送达时间、1–30 天有效期与备注
- [x] 装卸货地址按省/市/区加详细地址结构化保存；联系人姓名、电话与详细地址属于隐私字段
- [x] 发布后订单状态为待接单，订单池投影只包含公开信息，不出现收货联系人、电话、详细地址与备注
- [x] 货主可在“我的订单”按状态与时间范围查看自己发布的订单，不能查看其他货主订单
- [x] 只有已实名且入驻通过的货主可以发布，未通过时接口拒绝
- [x] 后端 HTTP API 测试覆盖草稿、发布、隐私投影、货主数据隔离与资格拦截
