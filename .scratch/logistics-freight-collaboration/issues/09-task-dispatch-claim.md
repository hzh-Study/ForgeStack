# 09: 指派、开放自抢与司机领取

**What to build:** 物流公司可以把任务指派给指定司机与车辆，或开放到公司任务池让司机自抢；司机领取采用先到先得且只有一人成功；司机可查看自己的任务并确认知悉；指派与领取都会校验车辆可用与一车一单。

**Blocked by:** 05, 08

**Status:** resolved

- [x] 物流公司可指派任务给本公司司机及其绑定车辆，指派后任务归属锁定
- [x] 物流公司可把任务开放到公司任务池，任务出现在本公司司机的可领取列表
- [x] 公司任务池领取前只展示公开信息，领取成功后才开放完整收货信息
- [x] 并发领取同一任务只有一名司机成功，其余返回任务已被领取
- [x] 司机可确认知悉指派，确认不改变任务归属；拒绝只能走弃单
- [x] 车辆维修或停用、司机或车辆已有运输中任务时，指派与领取都被拒绝
- [x] 司机可在小程序与司机 Web 按状态查看自己的任务
- [x] 后端 HTTP API 测试覆盖指派锁定、并发领取唯一、知悉确认、车辆状态与一车一单校验
