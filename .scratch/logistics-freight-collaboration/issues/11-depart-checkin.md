# 11: 出发打卡

**What to build:** 司机在小程序装货点提交出发打卡，上传当前位置、提交时间、装货完成照片与车辆状态照片；系统按约定提货时间起 20 分钟标记按时或超窗，允许首次提交后 20 分钟内重复提交，之后锁定并仅可追加说明。

**Blocked by:** 10

**Status:** resolved

- [x] 出发打卡必须同时具备提交时间、当前位置与至少两张带用途照片（装货完成、车辆状态）
- [x] 照片可从相册选取，不校验拍摄时间与地点；单文件与数量限制生效
- [x] 提交成功后任务进入运输中；同一司机与车辆不能同时存在两个运输中任务
- [x] 按约定提货时间起 20 分钟标记按时或超窗；首次打卡全天允许，早到与迟到都能提交
- [x] 首次提交后 20 分钟内可重复提交多版本，最后一版为有效版本，历史版本永久保留
- [x] 20 分钟后锁定打卡内容，只能追加文字说明，记录追加人与时间
- [x] 后端 HTTP API 测试覆盖凭证完整性、按时与超窗、重复提交窗口、锁定与追加说明
