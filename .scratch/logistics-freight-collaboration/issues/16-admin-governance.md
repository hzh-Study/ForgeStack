# 16: 管理员监管与治理

**What to build:** 管理员在后台只读查看全平台订单、运单、任务、打卡、照片、签收、报销与审核历史；维护基础资料与平台默认参数；查询操作留痕与消息发送记录；停用账号前校验进行中业务。

**Blocked by:** 04, 12, 14

**Status:** resolved

- [x] 可按货主、物流公司、司机、时间与状态查询全平台业务链路，包含打卡各版本、照片、签收凭证、报销与审核历史
- [x] 管理员对业务记录只有只读权限，系统不提供修改或删除业务记录的接口
- [x] 可维护货物类型、费用类型、车辆类型、地区、订单有效期默认值、提醒时点与月度额度默认值
- [x] 可查询入驻审核、账号停用启用与基础资料变更的操作人与时间
- [x] 可查看全平台消息发送记录，但不能修改消息内容
- [x] 停用司机前校验无待执行或运输中任务；停用物流公司前校验无未完成运单
- [x] 文件访问经后端鉴权，管理员可读，未授权角色不可读
- [x] 后端 HTTP API 测试覆盖只读边界、监管查询、默认可维护、操作留痕与停用校验
