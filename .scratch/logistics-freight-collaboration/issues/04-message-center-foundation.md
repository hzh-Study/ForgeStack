# 04: 消息中心基础

**What to build:** 三个端都有消息中心：系统通知按业务事件写入，站内消息按会话收发，铃铛显示未读条数；管理员可与各角色发起会话，打开会话即标记已读。

**Blocked by:** 03

**Status:** resolved

- [x] 系统通知可按业务事件写入，按时间倒序展示，永久保留发送对象、时间、内容与已读状态
- [x] 管理员可与任一角色建立会话并收发文本；无关角色之间的非法会话被拒绝
- [x] 铃铛未读数为未读消息条数；打开会话即把该会话消息标记已读，系统通知逐条标记已读
- [x] 未读数与消息列表按 30 秒轮询刷新，进入会话立即拉取；不引入 WebSocket
- [x] 三个端都能查看通知列表、会话列表与会话内容
- [x] 后端 HTTP API 测试覆盖会话权限、未读统计、已读标记与消息不可删除
