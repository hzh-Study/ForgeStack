# 02: 实名自动校验与唯一身份

**What to build:** 四种角色都能提交实名信息，系统通过本地模拟适配器自动校验并记录通过或不通过的原因；一个实名身份只能绑定一个角色；证件号按脱敏规则展示。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 各端可提交真实姓名、证件类型与证件号、本人手机号，校验结果与不通过原因落库
- [ ] 同一证件号重复绑定其他角色被拒绝；一个实名身份不能同时拥有两个角色
- [ ] 企业法定代表人校验与企业实名身份相互独立，不占用法定代表人的个人角色名额
- [ ] 列表与物流公司视图中的证件号脱敏为前 3 位加后 4 位，本人与管理员可见完整号码
- [ ] 实名校验通过后不可修改，变更只能停用旧账号并按新实名重新创建
- [ ] 后端 HTTP API 测试覆盖校验通过与拒绝、唯一身份冲突、法人独立与脱敏展示
