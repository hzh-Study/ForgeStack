# 07: 订单池与并发接单

**What to build:** 已入驻的物流公司可以浏览订单池公开信息、筛选排序并接单；多家公司并发接同一订单时只有一家成功，其余收到“已被接走”；接单后完整信息对该物流公司开放，并产生运单身份。

**Blocked by:** 06

**Status:** resolved

- [x] 订单池只对已实名且入驻通过的物流公司开放，只展示公开信息且不展示备注
- [x] 支持按起止地、货物类型、运费、发布时间与剩余时间筛选排序
- [x] 接单使用条件更新，同一订单并发接单仅一家成功，其余返回明确的已被接走提示
- [x] 接单即接受货主报价；订单归属该公司、状态变为已接单、从订单池移除，完整信息对该公司的任务司机开放
- [x] 接单成功后生成运单身份，物流公司可在“我的运单”看到该运单及货主信息
- [x] 已撤回、已取消、已下架的订单不能被接单
- [x] 后端 HTTP API 测试覆盖并发抢单唯一、完整信息开放、非法状态拒绝与公司数据隔离
