# 05: 司机与车辆管理

**What to build:** 物流公司可以创建旗下司机与车辆，录入驾驶证与行驶证信息，建立一名司机只绑一台车的一对一关系，并在司机无进行中任务时调整绑定并留痕；司机账号可登录小程序与司机 Web。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 物流公司可创建司机账号，录入实名信息、手机号、驾驶证号与有效期、初始密码，并绑定一台本公司车辆
- [ ] 车辆可维护车牌、车型、归属公司、行驶证号与有效期、状态（正常/维修/停用）与资质资料
- [ ] 司机与车辆严格一对一：一台车不能绑定两名司机，一名司机不能绑定两台车
- [ ] 绑定调整仅在司机无待执行或运输中任务时允许，并记录操作人、时间与调整前后车辆
- [ ] 司机有进行中任务时不能被停用；维修或停用状态在车辆与调度视图中明确展示
- [ ] 物流公司只能管理本公司司机与车辆，不能查看其他公司数据
- [ ] 后端 HTTP API 测试覆盖创建、绑定、调整留痕、唯一绑定与数据隔离
