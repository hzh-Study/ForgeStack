# 17: 全链路验收

**What to build:** 用一条可重复的验收路径跑通完整主流程：管理员审核入驻 → 货主发布 → 物流公司抢单 → 拆分与指派或自抢 → 司机出发与到达打卡 → 运单完成 → 报销审核 → 消息通知；并回归全部后端 API 测试。

**Blocked by:** 15, 16

**Status:** ready-for-agent

- [ ] 一条可重复执行的验收路径覆盖管理员审核、货主发布、并发抢单、拆单派车、司机打卡、运单完成、报销与消息
- [ ] 验收中核对隐私投影：接单前看不到收货人、电话、详细地址与备注，接单后与领取任务后才开放
- [ ] 验收中核对一车一单、并发唯一、超窗打卡、弃单回收、取消边界与超限特殊审核
- [ ] 后端全部 HTTP API 测试通过，无失败或跳过项
- [ ] 三端浏览器冒烟通过：后台入驻审核、前台发布与抢单、小程序打卡
- [ ] 无遗留阻塞缺陷，验收结果记录在 ticket 评论中
