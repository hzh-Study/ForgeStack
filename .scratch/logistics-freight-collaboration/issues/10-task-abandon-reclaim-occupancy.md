# 10: 弃单、回收与一车一单

**What to build:** 任务未出发时，司机可以弃单、物流公司可以强制回收，任务回到待指派并可重新指派或再次开放自抢；未出发任务的货物分配可调整并通知司机；所有退出与调整都留痕。

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 司机弃单必须填写原因并二次确认，任务回到待指派，原领取记录保留
- [ ] 物流公司强制回收必须填写原因并二次确认，任务回到待指派，可重新指派或再次开放自抢
- [ ] 任务出发后不能弃单、不能回收、不能改派
- [ ] 任务未出发前可调整承载货物，需留痕并通知已被指派的司机，出发后锁定
- [ ] 出发打卡时再次校验该司机与车辆没有其他运输中任务，保证一车一单
- [ ] 弃单、回收、货物调整的历史记录对物流公司与管理员可查
- [ ] 后端 HTTP API 测试覆盖弃单、回收、重新指派、货物调整、出发占用与状态拒绝
