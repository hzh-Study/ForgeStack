# 13: 订单生命周期补充

**What to build:** 货主可撤回待接单订单；接单后全部任务未出发时货主或物流公司可取消；系统在到期前 2 天、1 天、1 小时提醒货主，到期自动下架；仅已下架订单可一键重发，撤回与取消只能新建货源。

**Blocked by:** 07

**Status:** resolved

- [x] 待接单订单可撤回，撤回后立即从订单池移除，状态为已撤回
- [x] 接单后全部任务未出发时，货主或物流公司可取消，需填写原因与二次确认，并通知相关方
- [x] 任一任务出发后取消请求被拒绝；取消时未出发任务置为已终止
- [x] 到期前 2 天、1 天、1 小时各产生一次提醒，到期无人接单自动下架
- [x] 提醒与自动下架幂等执行；订单被接走、撤回或取消后未到点的提醒与下架立即失效
- [x] 仅已下架订单支持一键重发，生成新订单并重置有效期与提醒，记录来源订单与重发次数
- [x] 已撤回与已取消订单不支持一键重发；货主可查看订单的提醒历史
- [x] 后端 HTTP API 测试覆盖撤回、取消边界、提醒幂等、自动下架与重发范围
