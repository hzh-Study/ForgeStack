# 03: 企业入驻与管理员审核

**What to build:** 货主与物流公司提交企业主体资料和法定代表人实名信息，管理员在后台人工审核；审核结果决定能否发布货源或进入订单池；管理员可停用启用账号并留下操作痕迹。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 货主与物流公司可提交主体名称、统一社会信用代码、联系人、联系电话、资质附件、所在地区与经营范围，提交后状态为待审核
- [ ] 法定代表人实名未通过时不能提交入驻申请；实名校验与入驻审核保持两个独立环节
- [ ] 管理员可通过或驳回入驻申请，驳回必须填写原因，记录审核人与审核时间，管理员不审核实名本身
- [ ] 未通过入驻的货主不能发布货源，未通过入驻的物流公司不能查看订单池与接单，接口层强制校验
- [ ] 管理员可停用或启用任一角色账号，停用后不能登录与执行业务操作，历史记录保留可查
- [ ] 入驻审核与账号停用启用可查询操作留痕
- [ ] 后端 HTTP API 测试覆盖入驻状态流转、资格拦截、停用启用与审核留痕
