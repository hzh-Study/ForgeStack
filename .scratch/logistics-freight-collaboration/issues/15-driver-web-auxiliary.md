# 15: 司机 Web 辅助端

**What to build:** 司机在前台用户端的辅助工作台查看自己的任务与全部现场记录、提交与重提报销、查看额度、与所属物流公司收发站内消息；Web 端不提供现场打卡与照片上传入口。

**Blocked by:** 12, 14

**Status:** resolved

- [x] 司机 Web 可查看本人全部任务、任务货物明细、约定时间、执行状态与所属运单概况
- [x] 可查阅本人全部出发/到达打卡版本、照片、签收凭证与追加说明，并按任务与时间筛选
- [x] 可提交报销、查看驳回原因、修改重提、查看当月累计与剩余额度
- [x] 可与所属物流公司收发站内消息，查看系统通知与未读数
- [x] 页面不出现出发打卡、到达打卡、现场照片与签收凭证上传入口
- [x] 司机只能看到本人数据，不能查看其他司机任务、打卡、车辆或报销
- [x] 浏览器冒烟验证任务查看、记录查阅、报销提交与消息收发；后端接口复用已有 API 测试
